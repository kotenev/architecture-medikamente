## 2. Список проблемных зон

### 2.1 Критические проблемы (требуют немедленного решения)

П-001: отсутствие шифрования данных at-rest
- Описание: все конфиденциальные данные хранятся в незашифрованном виде
- Затронутые системы: файловый сервер, 1С Бухгалтерия, 1С Торговля и склад
- Нарушение: ФЗ-152 "О персональных данных", Приказ ФСТЭК №21
- Риск: Утечка данных при физическом доступе к серверу или резервным копиям

П-002: Отсутствие шифрования данных in-transit
- Описание: передача данных по сети осуществляется по незащищённым протоколам (SMB/CIFS без шифрования)
- Затронутые системы: файловый сервер, ККМ -> 1С
- Нарушение: ФЗ-152, требования безопасности медицинских ИС
- Риск: перехват данных при передаче по локальной сети

П-003: ПДн в именах файлов и папок
- Описание: папки пациентов названы по схеме "Pacient1-FIO-BD", что раскрывает ПДн в файловой системе
- Затронутые системы: файловый сервер
- Нарушение: принцип минимизации данных (Privacy by Design)
- Риск: утечка ПДн через метаданные, логи, резервные копии

П-004: отсутствие разграничения доступа к данным пациентов
- Описание: все сотрудники имеют доступ ко всем файлам пациентов через общую папку
- Затронутые системы: файловый сервер
- Нарушение: принцип минимальных привилегий, ФЗ-152
- Риск: несанкционированный доступ, внутренние утечки

П-005: отсутствие аудита доступа к конфиденциальным данным
- Описание: не ведётся журнал доступа к файлам и операций с данными
- Затронутые системы: все системы
- Нарушение: требования к ИСПДн, невозможность расследования инцидентов
- Риск: невозможность выявления утечек и их расследования

### 2.2 Высокие проблемы (требуют решения в краткосрочной перспективе)

П-006: слабая аутентификация в 1С
- Описание: 1С работает в файловом режиме без централизованной аутентификации
- Затронутые системы: 1С Бухгалтерия, 1С Торговля и склад
- Риск: несанкционированный доступ к финансовым данным

П-007: небезопасная интеграция с лабораторией**
- Описание: результаты анализов передаются через email и файлы без шифрования
- Затронутые системы: Exchange Mail Server, файловый сервер
- Нарушение: требования к защите медицинских данных
- Риск: утечка медицинской информации при передаче

П-008: отсутствие классификации и маркировки данных
- Описание: данные не классифицированы по уровню конфиденциальности
- Затронутые системы: все системы
- Нарушение: принципы Data Governance
- Риск: невозможность применения дифференцированных мер защиты

П-009: ручная обработка конфиденциальных данных
- Описание: все операции с данными выполняются вручную без автоматизированного контроля
- Затронутые системы: Excel-файлы, процессы регистрации
- Риск: человеческие ошибки, избыточный сбор данных

### 2.3 Средние проблемы (требуют планирования)

П-010: отсутствие политики хранения и удаления данных
- Описание: нет регламента сроков хранения и процедуры удаления ПДн
- Нарушение: право на удаление данных (ФЗ-152)

П-011: Отсутствие резервного копирования с защитой
- Описание: нет информации о защищённом резервном копировании
- Риск: потеря данных, доступ к незащищённым резервным копиям

П-012: передача данных ККМ по незащищённому каналу
- Описание: ККМ передаёт данные в 1С по TCP/IP-OLE без шифрования
- Риск: перехват платёжной информации
