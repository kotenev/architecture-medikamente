## Выполненные задачи

### 1. Выявление конфиденциальных данных

Идентифицированы категории данных:

| Категория             | Примеры                               | Уровень риска       |
|-----------------------|---------------------------------------|---------------------|
| Базовые ПДн           | ФИО, дата рождения, контакты, паспорт | Высокий/Критический |
| Специальные ПДн (PHI) | Диагнозы, анализы, история болезни    | Критический         |
| Финансовые данные     | Платежи, банковские реквизиты         | Высокий             |

### 2. Диаграммы потоков данных (DFD)

AS-IS диаграммы:
- DFD Level 0: общий контекст системы
- DFD Level 1: основные процессы
- DFD 1.0: регистрация пациента (детализация)
- DFD 3.0: приём пациента врачом
- DFD 4.0: обработка результатов анализов
- DFD 5.0: оплата медицинских услуг

TO-BE диаграммы:
- DFD Level 1: с мерами защиты
- DFD 1.0: регистрация с Privacy by Design
- DFD 4.0: защищённая интеграция с лабораторией

### 4. Меры защиты

Методы защиты по типам данных:
- Шифрование: AES-256 at-rest, TLS 1.3 in-transit, HSM для критичных ключей
- Обфускация: маскирование для логов и отображения
- Обезличивание: псевдонимизация для аналитики, UUID вместо ФИО

### 5. Механизм тегирования

Схема тегов:
```
TAG-{CATEGORY}-{NUMBER}
  CATEGORY: PII | PHI | FIN | INT
  NUMBER: 001-999
```

Примеры тегов:
- TAG-PHI-001: диагноз пациента
- TAG-PHI-002: результаты анализов  
- TAG-PII-001: ФИО пациента
- TAG-PII-002: паспортные данные
- TAG-FIN-001: данные платежа

### 6. Инструменты защиты

| Область     | Инструмент                      | Назначение               |
|-------------|---------------------------------|--------------------------|
| Шифрование  | BitLocker, TDE, HashiCorp Vault | At-rest encryption       |
| Транспорт   | TLS 1.3, mTLS, S/MIME           | In-transit encryption    |
| Доступ      | AD + RBAC, MFA, PAM             | Контроль доступа         |
| Аудит       | Wazuh SIEM, File Auditing       | Мониторинг и логирование |

| DLP         | Microsoft Defender DLP          | Предотвращение утечек    |
